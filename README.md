# Desenvolvimento de Interfaces

Repositório com os projetos, exercícios e anotações da disciplina de Desenvolvimento de Interfaces, cursada em 2026, no CEUB.

## Sobre a disciplina

- **Período:** 2º semestre de 2026
- **Professor(a):** Felipe Batista
- **Foco:** criar interfaces web que sejam bonitas, funcionais, acessíveis e centradas no usuário.

## O que eu aprendi

### Desenvolvimento web
- **HTML:** estrutura semântica de páginas, formulários, listas, tabelas e links
- **CSS:** seletores, box model, cores, tipografia, Flexbox, Grid e responsividade

### Acessibilidade
- **WCAG:** os quatro princípios (perceptível, operável, compreensível e robusto)
- Contraste de cores, texto alternativo em imagens, navegação por teclado e uso correto de rótulos em formulários

### Design e usabilidade
- **Design Thinking:** empatizar, definir, idear, prototipar e testar
- **Heurísticas de Nielsen:** as 10 heurísticas de usabilidade e como aplicá-las na avaliação de interfaces

### Outros tópicos
- Interação humano-computador;
- UX e UI;
